# Shantiram Meche Portfolio

This is a Progressive Web App (PWA) portfolio showcasing my work as a Full Stack Developer.

## 🚀 Installation Guide

### **Windows Installation (Edge, Chrome, Brave)**

#### Method 1: Using the Browser Menu (Recommended)
1. Open your portfolio website in **Microsoft Edge**, **Google Chrome**, or **Brave Browser**
2. Click the **⊕ Install** button in the address bar (appears on the right side)
3. Click **"Install"** in the popup dialog
4. Your portfolio app will be installed and appear on your desktop/Start Menu

#### Method 2: Using Browser Menu
1. Open the portfolio in supported browser
2. Click the **three-dot menu** (⋯) in the top-right corner
3. Select **"Apps"** → **"Install this site as an app"**
4. Confirm the installation

#### Method 3: From Start Menu
1. After using Method 1 or 2, the app appears in your Windows Start Menu
2. You can pin it to your taskbar or create a shortcut on your desktop

**Compatible Browsers:**
- ✅ Microsoft Edge (Recommended)
- ✅ Google Chrome v90+
- ✅ Brave Browser
- ❌ Firefox (limited PWA support)

---

### **iOS Installation (iPhone & iPad)**

#### Method: Using Safari (Built-in App Shortcut)
1. Open your portfolio in **Safari** browser
2. Tap the **Share** button (arrow icon at the bottom-center)
3. Scroll down and select **"Add to Home Screen"**
4. Choose a name (e.g., "SM Portfolio") or use the default
5. Tap **"Add"** in the top-right corner
6. The app will be added to your home screen as a native-like app

**Supported Devices:**
- ✅ iPhone 6s or newer
- ✅ iPad (all modern models)
- ✅ iPod Touch (6th generation or newer)

**Note:** iOS PWAs don't appear in the App Store, but work seamlessly from the home screen.

## 🔧 Troubleshooting

### App won't install on Windows?
- ✅ Make sure you're using Edge, Chrome, or Brave
- ✅ Check if HTTPS is enabled (PWAs require HTTPS)
- ✅ Clear browser cache and try again
- ✅ Make sure manifest.json is valid

### App won't install on iOS?
- ✅ Use Safari browser (not Chrome or Firefox)
- ✅ Ensure you have enough storage space
- ✅ Try force-restarting Safari
- ✅ Check iOS version (iOS 11.3+ required)

### App is crashing?
- ✅ Force-close the app (swipe up from the bottom)
- ✅ Clear app cache or reinstall
- ✅ Check your internet connection
- ✅ Update to the latest browser version
